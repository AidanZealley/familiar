Familiar runs on your own machine and keeps a single conversation going across restarts. You chat with it from any of your devices. It files away facts and daily summaries overnight, runs reminders in the same conversation and can search the web or call tools you connect. It is built on [Pi Durable](https://github.com/earendil-works/pi/tree/main/packages/durable), which keeps its work durable through crashes and restarts.

## Install

<Tabs syncKey="platform">
<TabItem label="macOS">

```sh
curl -fsSL https://github.com/AidanZealley/familiar/releases/latest/download/install.sh | sh
```

</TabItem>
<TabItem label="Linux">

```sh
curl -fsSL https://github.com/AidanZealley/familiar/releases/latest/download/install.sh | sh
```

</TabItem>
<TabItem label="Windows">

```powershell
irm https://github.com/AidanZealley/familiar/releases/latest/download/install.ps1 | iex
```

</TabItem>
</Tabs>

The installer asks for a name and signs you in with your ChatGPT subscription. You don't need an API key. It then starts Familiar in the background and prints the URL to open. [Install and first chat](/familiar/use/install/) walks through each step.
